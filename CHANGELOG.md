# Changelog

All notable changes to the AI Campus Placement Agent project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial open source project structure
- Multi-agent architecture with Coordinator, Resume, JobMatch, SkillGap, Roadmap, and Interview agents
- Flask web application with responsive UI
- PDF resume parsing and analysis
- Job description matching and scoring
- Skill gap analysis with prioritized learning paths
- 6-week study roadmap generation
- Interactive mock interview simulator with real-time evaluation
- PDF report generation using ReportLab
- Company profiles for major tech companies (Google, Microsoft, Amazon, TCS, Infosys, Accenture, Capgemini, Wipro)
- SQLite database for analysis and interview session persistence
- Comprehensive documentation (README, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY)
- GitHub Actions CI/CD pipeline
- Issue and pull request templates
- Docker support (via Dockerfile)
- Python package configuration (pyproject.toml)

### Security
- Input validation for file uploads
- Environment variable management for API keys
- Security policy documentation
